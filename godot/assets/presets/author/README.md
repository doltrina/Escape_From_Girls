# 🎨 Авторский пресет (Author Preset / 18+)

Эта папка предназначена для авторских материалов (изображений, видеороликов и музыки).

⚠️ **ВНИМАНИЕ**: Данная папка добавлена в `.gitignore`. Все находящиеся здесь файлы (изображения, видео `.mp4`/`.ogv`, музыка `.mp3`, а также служебные файлы `.import` от Godot) **НЕ попадут в репозиторий GitHub**.

### Ожидаемые файлы пресета:
* `girl.png` — Спрайт / текстура преследующей девушки (для лабиринта и вулкана)
* `game_over.png` — Картинка экрана поражения (если видео не поддерживается)
* `game_over.ogv` / `game_over.mp4` — Видеоролик экрана поражения (Game Over)
* `victory.ogv` / `victory.mp4` — Видеоролик экрана победы (Victory)
* `girl_music.mp3` — Музыка погони (опционально)

Если какой-либо файл отсутствует в этой папке, игра автоматически и безопасно использует стандартный ресурс из папки `godot/assets/presets/standard/`.
