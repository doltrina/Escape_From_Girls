# 🎨 Папка Авторских Настроек (Author Preset)

Сюда можно положить свои файлы контента, которые автоматически подгрузятся по кнопке **«⭐ Авторские настройки»** в меню кастомизации:

1. **`girl.png`** (или `girl.jpg`) — текстура / фото девушки (Nextbot), которая будет гоняться за игроком.
2. **`game_over.mp4`** (или `.webm`) — видео, которое проигрывается при поимке (проигрыш).
3. **`girl_music.mp3`** (или `.wav`) — музыка погони девушки (громкость нарастает при приближении).
4. **`victory.mp4`** (или `.webm`) — видео счастливого конца (побега).
5. **`victory_music.mp3`** — музыка победы (если требуется).
